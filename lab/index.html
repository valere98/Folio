Spacing changes personality.

Tracking changes the density and rhythm of a word. Tight spacing can feel compact; generous spacing can feel open, but too much may slow recognition.

03

Why some motion feels natural.

Linear movement changes at a constant rate. Easing changes speed over time, which can feel softer or more deliberate. Neither is always better.

TRY IT · TIMING

Watch how the start and stop affect the perceived weight.

04

Expression has a reading cost.

Motion can bring attention to a short headline. Apply the same movement to longer text and it may compete with reading. Use only as much as the context can support.

03 / TRANSFORM
Work with the data

              

                
                
                
                
                
              

              
Sort changes display order only. JSON objects are commonly treated as unordered; confirm requirements before relying on key order.

              
CSV escaping protects delimiters and quotes, not spreadsheet formulas. Review untrusted cell values before opening a CSV in a spreadsheet.

            

          

          
All parsing and transformations happen locally in your browser. Repair suggestions are intentionally conservative; ambiguous syntax is reported, not guessed.

          

            Why strict JSON rejects these files—and when a repair is safe
            

              
Strings and keys need double quotes. JSON is stricter than JavaScript object syntax, so single-quoted strings and unquoted property names are not valid JSON.

              
Syntax is not a schema. Valid JSON does not confirm that an API or application will accept its field names, value types, or structure.

              
Commas separate items; they do not finish them. A comma immediately before a closing bracket or brace is invalid. This bench can identify and remove that exact comma.

              
Comments are not part of JSON. Line and block comments can be removed outside strings. Text such as https:// inside a quoted value is preserved.

              
Some mistakes need a human. Missing values or ambiguous separators are not guessed. Every proposed repair is parsed again and shown for review before it can replace the input.
