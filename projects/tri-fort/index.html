Tri Fort Builders

A server-rendered public site and role-based operations platform for connected construction workflows.

Visit live website ↗

Overview

Shared data for public and operational experiences.

The public website and operations portal use a shared, normalized data model for projects, estimates, invoices, content, and customer records. Next.js Server Components handle server-side data fetching, while typed API boundaries keep application data consistent.

My role: Lead Full-Stack Engineer, responsible for architecture and implementation.

Technology

  • Next.js
  • TypeScript
  • React Server Components
  • Node.js
  • PostgreSQL
  • Image processing
  • Authentication
  • File storage
  • SEO optimization

The problem

Projects, estimates, invoices, and customer updates were split across disconnected tools. These workflows needed a shared schema and reliable typed boundaries.

The solution

The implementation separates a server-rendered public site from a role-based administration portal. The portal brings project management, quotation workflows, financial tracking, invoice generation, content management, and customer communication together around shared records.

Architecture

A normalized PostgreSQL model anchors project and estimating records, including hierarchical estimation items. Typed API boundaries keep records consistent across workflows, and Server Components handle secure server-side reads.

Technical decisions

Server Components support server-side data fetching and fast initial loads. Strict TypeScript typing across the API layer helps catch data mismatches before runtime.

Engineering highlights

  • Built a CMS for staff-managed website content.
  • Connected project lifecycle management from quotation through completion.
  • Integrated invoice generation and financial tracking with project records.
  • Implemented validated media uploads and image optimization.
  • Developed reusable administration components and a responsive dashboard for field and office workflows.
  • Optimized the public site for SEO alongside an authenticated administration experience.

Results

Project, estimating, and billing workflows share normalized records; typed API boundaries help catch data mismatches before runtime; and the role-based operations portal supports work alongside the public site.
